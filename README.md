# 星核幸存者 · Planetcore Survivors

一款 2D 太空肉鸽割草游戏。你是一颗行星，在无尽的深空中迎击敌潮、吸收星尘、进化构筑，活过 8 分钟并击碎虚空吞噬者。

选择地球、太阳、木星或暗星，搭配巡航、深空、虚空三档难度；通关一次后解锁无尽深空。

## 启动

**Windows 一键启动：** 双击 `play.bat`，浏览器会自动打开游戏。

**手动启动：**

```bash
node server.js
```

然后访问 <http://127.0.0.1:4173>。

> 游戏使用 ES Module，直接双击 `index.html` 会被浏览器的本地文件策略拦截，请通过上面的本地服务器启动。

## 操作

- `WASD` / 方向键：移动
- 多数星核自动攻击并锁定最近敌人；太阳需要主动蓄力
- **`空格` / 鼠标右键 / 触屏能力按钮**：发动当前星球专属能力
- `1` / `2` / `3`：升级时选择强化
- `R`：重掷当前这组强化，每组一次
- `Esc` / `P`：暂停
- `M`：静音
- `F`：全屏
- 鼠标：其他星球按住左键朝光标方向移动
- 地球：按一次进入星轨过载，再按一次退出
- 太阳：自动蓄力，按下空格释放激光；选择星球时可开启“自动攻击”，蓄满后自动发射
- 木星：按住展开引力场，松手释放斥力
- 暗星：点击/轻触战场跃迁，鼠标指向后按 `Q` 也可跃迁（无法用 WASD 移动）；充能全满时按空格展开黑洞
- 暗星跃迁可存 3 格，每格 3 秒依次回充
- 触屏：其他星球左侧拖动呼出虚拟摇杆

## 星球

- **地球 · 轨道文明**：自带可持续释放引力波的月球；每 30 秒发射一颗卫星，最多 5 颗，过剩卫星脱轨自毁。按空格进入星轨过载：移速 +30%、召唤物攻速翻倍，再按一次或耗尽充能退出
- **太阳 · 日冕齐射**：伤害 +16%，最大生命 -15%；自动蓄力，按下空格释放激光，蓄得越久光束越宽、伤害越高。每 5 次击发积攒一点充能，满 5 点后下一次攻击连续释放 6 道激光
- **木星 · 引力洪流**：最大生命 +35%，移速 -10%，每秒恢复 0.7 生命；每 4.8 秒释放风暴击退敌群；按住空格积蓄引力，期间获得 28% 伤害减免
- **暗星 · 视界坍缩**：无法移动，点击屏幕可进行跃迁，并在跃迁路径留下暗轨。跃迁最多储存 3 次，每 3 秒恢复一次；充能完全时按下空格化身黑洞，期间不会受到伤害并持续牵引敌人和弹幕，结束时爆炸并击退存活者；黑洞期间无法主动取消

## 难度

- **巡航**：标准体验，适合第一次进入深空
- **深空**：敌人更硬、更密，精英出现更频繁
- **虚空**：高血量、高伤害、高密度
- **无尽深空**：首次通关后解锁；Boss 会反复归来，每只更强，比拼存活时间

## 突破

每个星球有一条唯一突破，满足两个前置强化等级后会在升级卡中以金色卡出现：

- **地球 · 月轨炮阵**：人造卫星网络 + 月潮共振。月球额外释放引力波，卫星额外发射子弹并获得穿透
- **太阳 · 日冕熔线**：光束聚焦 + 日珥灼烧。激光路径留下持续灼烧轨迹
- **木星 · 潮汐奇点**：深空引力 + 超新星脉冲。引力释放后留下持续牵引并二次爆炸的奇点
- **暗星 · 折叠视界**：折叠引擎 + 事件视界。跃迁轨迹延迟坍缩，整条路径再次造成伤害

## 内容

- 8 分钟完整流程：普通敌人、裂变怪、盾卫、自爆孢子、虚空祭司、周期精英、双阶段 Boss
- 24 种可叠加强化；升级页固定分为“通用强化”和“当前星球专属强化”两栏，图鉴强化页可按通用或四颗星球筛选
- 星核裂变使所有伤害 +30%；脉冲超频使普攻、召唤物与太阳蓄力间隔缩短 20%；再生星云每秒恢复 1 点生命
- 4 条星球专属突破；图鉴会标注「通用 / 星球专属」和具体作用范围，避免“子弹伤害是否作用于激光”这类歧义
- **独有机制：四星球独立空格能力**
  - 与常见“所有角色共用冲刺或炸弹”的割草游戏不同，四颗星核拥有完全不同的主动输入与资源循环；
  - 地球切换持续耗能的轨道过载，太阳自动蓄力并按空格爆发，木星按住聚怪并松手释放，暗星则必须等资源充满后进入不可取消的吞噬黑洞；
  - 木星仍可使用可控引力场把周围敌人和弹幕吸成团；
  - 木星引力范围随蓄力从 75% 扩大到 125%，松开后按吸入的敌人数造成范围伤害与击退；
  - 敌弹会被拉弯并拖入内圈，被捕获的弹幕会转化为释放伤害与能量返还；
  - 松手后进入 0.7 秒冷却；快速点按只能产生弱推力，无法清弹，必须判断释放时机；
  - 满蓄力释放会触发“完美引力”，获得额外伤害与金色冲击波；
  - 木星引力会消耗能量、降低移动速度，Boss 与精英具有抗性，不能无脑一直开。
- 星尘自动吸附、生命掉落、精英战利品、Boss 击杀与通关结算
- 星海图鉴：星球、敌人、强化、突破、事件五页，记录已遭遇内容
- 特殊事件：多波流星雨、虚空裂隙、星尘潮汐、太阳耀斑、赤线封锁
- 难度越高，事件间隔越短、流星波次/射线密度越高，危险事件出现概率也更高
- 程序化背景音乐与多层视差背景：四层星空、星云带、远景恒星、漂浮碎片与前景尘埃
- 最高记录保存在浏览器本地
- WebAudio 合成音效、环境低鸣与程序化 BGM，无需外部音频文件
- 键鼠与触屏自适应，支持全屏和暂停
- 结算界面带 1.6 秒输入保护，避免手机端死亡瞬间的触摸穿透导致误重启

## 文件结构

```
index.html        页面与 UI 结构
styles.css        界面、升级卡、结算页样式
js/config.js      数值、敌人定义、强化池
js/audio.js       WebAudio 音效引擎
js/game.js        游戏循环、战斗、渲染、UI 逻辑
server.js         零依赖本地静态服务器
play.bat           Windows 一键启动
```

开发调试时访问 `http://127.0.0.1:4173/?debug=1` 可打开测试面板（加经验、模拟进度、召唤/击杀 Boss 等）。
